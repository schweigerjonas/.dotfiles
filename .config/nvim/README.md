# NeoVim

Personal [NeoVim](https://neovim.io/) configuration, based on [LazyVim](https://github.com/LazyVim/LazyVim).

### Spell Checking

For german spellchecking to work within `.tex` files, spellfiles (`.spl`, `.sug`) have to be
downloaded first. These can be found [here](https://ftp.nluug.nl/pub/vim/runtime/spell/).
